# Linux Basics for Hackers
## Модуль 4 — Керування програмним забезпеченням

---

## Про що цей модуль

Kali поставляється з готовими інструментами, але ти постійно будеш додавати нові, оновлювати існуючі або завантажувати щось напряму з GitHub розробника. Цей модуль пояснює, як Linux керує встановленням програм — це зовсім не схоже на Windows — і як отримувати інструменти, яких немає в стандартній бібліотеці.

---

## Як Linux керує програмним забезпеченням

У Windows ти завантажуєш інсталятор з сайту, двічі клацаєш і проходиш майстер встановлення. Linux працює інакше.

Linux використовує **репозиторії** — величезні онлайн-бібліотеки програмного забезпечення, які підтримуються та перевіряються дистрибутивом. Замість пошуку посилання для завантаження ти просто говориш системі назву того, що хочеш, і вона знаходить, завантажує та встановлює це автоматично, включно з усіма бібліотеками, які потрібні для роботи.

Інструмент, який керує всім цим у Kali (і системах на базі Debian), — це `apt-get`.

Список репозиторіїв, які знає твоя система, знаходиться у файлі `sources.list` за шляхом `/etc/apt/sources.list`. Зазвичай цей файл краще не чіпати, якщо ти не знаєш, що додаєш — неофіційні репозиторії можуть містити зловмисні пакети.

---

## Команди

### apt-get update

Перш ніж щось встановлювати, виконай цю команду. Вона ніщо не встановлює й не оновлює — вона просто оновлює локальний список того, що доступно в репозиторіях. Якщо пропустити її і спробувати встановити щось, можна отримати застарілу версію або помилку.

```bash
apt-get update
```

Постарайся робити це перед кожним встановленням.

---

### apt-get install

Завантажує та встановлює пакет. Kali автоматично обробляє залежності — якщо інструмент потребує ще п'ять бібліотек для роботи, він їх також отримає.

```bash
apt-get install wireshark
```

Перед завантаженням система попросить підтвердження. Введи `y` і натисни Enter.

Щоб пропустити запит підтвердження:

```bash
apt-get install -y wireshark
```

Прапорець `-y` автоматично відповідає "так". Корисно, коли ти знаєш, що робиш.

---

### apt-get remove

Видаляє встановлений пакет.

```bash
apt-get remove wireshark
```

Це видаляє програму, але залишає її конфігураційні файли. Якщо хочеш видалити все, включно з конфігами:

```bash
apt-get purge wireshark
```

---

### apt-get upgrade

Оновлює всі встановлені пакети до останніх версій.

```bash
apt-get upgrade
```

Корисно запускати періодично, щоб інструменти були актуальними. Завжди спочатку запускай `apt-get update`, щоб оновити список пакетів перед оновленням.

---

### apt-cache search

Шукає у локальній базі даних репозиторіїв пакети за ключовим словом. Корисно, коли ти приблизно знаєш, що шукаєш, але не знаєш точну назву пакета.

```bash
apt-cache search wifi
```

Повертає список пакетів, у назві або описі яких є "wifi". Далі ти обираєш те, що виглядає правильно, і встановлюєш за назвою.

```bash
apt-cache search wireless
apt-cache search password crack
```

---

### git clone

Багато найкращих і новітніх хакерських інструментів не знаходяться в репозиторії — вони живуть на GitHub. `git clone` завантажує копію всього проєкту з GitHub напряму на твій комп'ютер.

```bash
git clone https://github.com/username/toolname
```

Це створює папку з назвою інструмента в поточній директорії. Більшість інструментів містять файл `README`, який пояснює, як їх встановити й запустити.

Загальний процес після клонування:

```bash
git clone https://github.com/example/tool
cd tool
```

Потім прочитай README з інструкціями по встановленню — зазвичай це щось на кшталт `pip install -r requirements.txt` або просто запуск Python-скрипта напряму.

> Багато найсвіжіших інструментів існують лише на GitHub. Навчання `git clone` на ранньому етапі означає, що ти не обмежений лише тим, що є в офіційних репозиторіях.

---

## Примітка про sources.list

Файл `/etc/apt/sources.list` містить URL-адреси всіх репозиторіїв, з яких система завантажує пакети. Його можна відкрити так:

```bash
cat /etc/apt/sources.list
```

Іноді в інтернеті знаходяться інструкції, які пропонують додати рядок у цей файл для доступу до стороннього репозиторію. Будь обережний. Офіційні репозиторії Kali підтримуються і перевіряються. Випадкові сторонні репозиторії — ні. Додавання неправильного джерела — простий спосіб встановити те, що ти зовсім не планував.

---

## Довідка по командам

| Дія | Команда |
|---|---|
| Оновити список пакетів | `apt-get update` |
| Встановити пакет | `apt-get install [name]` |
| Встановити без підтвердження | `apt-get install -y [name]` |
| Видалити пакет | `apt-get remove [name]` |
| Видалити разом із конфігами | `apt-get purge [name]` |
| Оновити всі пакети | `apt-get upgrade` |
| Пошук пакета | `apt-cache search [keyword]` |
| Клонувати з GitHub | `git clone [url]` |

---

## Практика

- Запусти `apt-get update`, щоб оновити список пакетів
- Використай `apt-cache search wifi` і подивись, що повернеться
- Вибери один інструмент із результатів і встанови його через `apt-get install`
- Знайди будь-який простий інструмент на GitHub і завантаж його на свій комп'ютер через `git clone`
