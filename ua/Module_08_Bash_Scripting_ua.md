# Linux Basics for Hackers
## Модуль 8 — Bash-скриптування

---

## Про що цей модуль

Хакер, який набирає одні й ті самі команди знову і знову, просто втрачає час. Скрипти — це спосіб автоматизувати це: ти пишеш команди один раз у файл, а потім просто запускаєш файл. Цей модуль пояснює, як писати Bash-скрипти — від простого "hello world" до чогось, що приймає вхідні дані і робить корисну роботу.

---

## Що таке скрипт

Скрипт — це звичайний текстовий файл, який містить список команд. Коли ти запускаєш його, Bash читає кожен рядок і виконує його по порядку так, ніби ти сам вводив ці команди в термінал. Різниця в тому, що це відбувається за секунди, і ти більше ніколи не набираєш їх вручну.

Ти можеш помістити в скрипт будь-яку команду, яку запускав би в терміналі: `ls`, `ping`, `nmap`, `grep` — усе працює. І їх можна комбінувати з логікою: якщо цей висновок містить цей рядок, виконуй іншу команду. У цьому й сила скриптів.

---

## Рядок shebang

Кожен Bash-скрипт починається з цього рядка на першому рядку:

```bash
#!/bin/bash
```

Це називається **shebang** (або hashbang). Він каже системі, яку програму використовувати для інтерпретації файлу. Без нього Linux може не знати, що робити з файлом — або використовувати не ту оболонку, і скрипт зламається дивним чином.

Завжди став його першим. Ніякого порожнього рядка перед ним, нічого.

---

## Створення першого скрипта

Відкрий текстовий редактор і створи файл `myscript.sh`:

```bash
#!/bin/bash
echo "Hello, world"
```

Збережи його. Тепер, перш ніж запускати, тобі треба зробити його виконуваним:

```bash
chmod 755 myscript.sh
```

Це дає тобі дозвіл запускати його як програму. Без цього кроку Linux відмовить у виконанні і напише "Permission denied".

Тепер запусти його:

```bash
./myscript.sh
```

Вивід:
```
Hello, world
```

`./` на початку означає "запустити цей файл з поточної директорії". Він потрібен, бо поточна директорія зазвичай не входить до `PATH`, і Linux не зможе знайти скрипт інакше.

---

## `echo` — виведення на екран

`echo` виводить те, що ти передав, у термінал. Це спосіб, яким скрипт спілкується з тобою.

```bash
echo "Scan starting..."
echo "Done."
```

Можна також виводити значення змінних:

```bash
echo "Your username is: $USER"
```

Вивід:
```
Your username is: kali
```

---

## Змінні в скриптах

Змінні дають змогу зберігати дані та використовувати їх повторно. Присвоєння виглядає так — пробілів навколо `=` не повинно бути:

```bash
name="Bob"
echo "Hello, $name"
```

Вивід:
```
Hello, Bob
```

Коли ти хочеш використати значення змінної, став перед її ім'ям `$`. Коли присвоюєш — `$` не ставиш.

---

## `read` — прийом введення від користувача

`read` зупиняє скрипт і чекає, поки користувач щось введе, після чого зберігає введене у змінну.

```bash
#!/bin/bash
echo "What is your name?"
read name
echo "Hello, $name"
```

Запусти його, і він почекає. Ти вводиш "Alice" і натискаєш Enter:

```
What is your name?
Alice
Hello, Alice
```

Також можна зробити це в одному рядку з прапором `-p` (prompt):

```bash
read -p "Enter your name: " name
```

Чистіше. Робить те саме.

## Практичний приклад — пінговий сканер

Це простий скрипт, який запитує IP-адресу і пінгує її. Це якраз те, що ти реально будеш використовувати:

```bash
#!/bin/bash
read -p "Enter IP address to ping: " target
echo "Pinging $target..."
ping -c 4 $target
```

`-c 4` каже ping відправити рівно 4 пакети і зупинитися. Без цього ping працює вічно.

Збережи як `pinger.sh`, зроби `chmod 755 pinger.sh`, і запускай через `./pinger.sh`.

## Коментарі

Будь-який рядок, який починається з `#`, — це коментар. Bash повністю його ігнорує. Використовуй їх, щоб пояснювати, що робить твій скрипт, особливо якщо щось неочевидне.

```bash
#!/bin/bash
# This script pings a target IP address
# Written for practice - Module 8

read -p "Enter target IP: " target
ping -c 4 $target   # send 4 packets only
```

Коментарі — для тебе (і будь-кого, хто читатиме скрипт пізніше). Пиши так, ніби через два тижні забудеш, що тут відбувається, бо саме так і буде.

---

## Умовна логіка — if/else

Коли ти можеш приймати рішення в скрипті, він стає справді корисним. Базовий синтаксис:

```bash
#!/bin/bash
read -p "Enter a number: " num

if [ $num -gt 10 ]; then
    echo "That number is greater than 10"
else
    echo "That number is 10 or less"
fi
```

`fi` закриває блок `if` (це просто "if" навпаки). `-gt` означає "greater than" (більше). Загальні оператори порівняння:

| Оператор | Значення |
|---|---|
| `-eq` | Рівно |
| `-ne` | Не дорівнює |
| `-gt` | Більше |
| `-lt` | Менше |
| `-ge` | Більше або дорівнює |
| `-le` | Менше або дорівнює |

Для порівняння рядків використовуй `=` і `!=` всередині дужок.

## Цикли — повторення дії

Цикл `for` запускає блок команд кілька разів:

```bash
#!/bin/bash
for i in 1 2 3 4 5; do
    echo "Pinging 192.168.1.$i"
    ping -c 1 192.168.1.$i
done
```

Це пінгує п'ять різних IP-адрес одну за одною. Це по суті примітивний мережевий сканер. Реальні сканери, такі як nmap, роблять це тисячі разів з набагато складнішою логікою, але концепція та сама.

---

## Робимо скрипти справді корисними — структура яка допомагає

Скрипт, який варто зберігати, зазвичай має таку форму:

```bash
#!/bin/bash
# Script name and what it does
# Your name, date

# --- Variables ---
target=""

# --- Input ---
read -p "Enter target: " target

# --- Main logic ---
echo "Running scan on $target..."
nmap -sV $target

# --- Done ---
echo "Scan complete."
```

Чіткі секції, коментарі там, де потрібне пояснення, і логіка йде зверху вниз. Тебе не обов'язково дотримуватися цього буквально, але така структура не дає скриптам перетворитися на незрозумілий набір рядків після того, як ти напишеш понад 20 рядків.

---

## Пам'ять про права доступу — `chmod`

Коли ти створюєш скрипт, за замовчуванням це звичайний текстовий файл. Щоб його запускати, треба встановити біт виконання.

```bash
chmod 755 myscript.sh
```

Що означає `755`:
- `7` — власник може читати, записувати і виконувати
- `5` — група може читати і виконувати
- `5` — інші користувачі можуть читати і виконувати

Для особистих скриптів, які запускаєш тільки ти, `chmod 700` теж вважається нормальним — тільки ти можеш робити з ними що завгодно.

---

## Довідка по командам

| Команда | Що робить |
|---|---|
| `chmod 755 script.sh` | Робить скрипт виконуваним |
| `./script.sh` | Запустити скрипт із поточної директорії |
| `read name` | Прийняти ввід від користувача |
| `read -p "Prompt: " name` | Прийняти ввід із текстом підказки |
| `if [ $var -gt 10 ]; then` | Умова порівняння |
| `for i in 1 2 3; do` | Для циклу |
| `while [ condition ]; do` | Цикл while |
| `echo "text"` | Вивести текст |

## Практика

- Створи простий скрипт, який виводить "Hello, world"
- Додай `read` і попроси користувача ввести своє ім'я, а потім привітай його
- Напиши скрипт, який перевіряє, чи введене число більше 10
- Зроби цикл `for`, який пінгує 192.168.1.1–192.168.1.5
- Поліпшить структуру свого скрипта так, щоб у ньому були секції Variables / Input / Main logic
