# Linux Basics for Hackers
## Модуль 9 — Архіви та стиснення

---

## Про що цей модуль

Іноді треба перемістити купу файлів як один пакет. Іноді треба зменшити розмір великого файлу перед відправкою кудись. А іноді — у форензицці або серйозному recon — потрібна точна копія всього диска побітово. Цей модуль охоплює всі три теми: архівування через `tar`, стискання через `gzip` і `bzip2`, і низькорівневе створення образів дисків через `dd`.

---

## Архівування vs стискання — це не одне й те саме

Ці два слова часто використовують як синоніми, але вони означають різні речі.

**Архівування** означає об'єднання кількох файлів в один. Воно не робить їх меншими — просто збирає разом. Інструмент для цього в Linux — `tar`.

**Стиснення** означає зробити файл меншим шляхом більш ефективного кодування. Інструменти для цього — `gzip` і `bzip2`. Вони працюють з окремими файлами.

На практиці зазвичай роблять обидва кроки: спочатку архівують, потім стискають результат. Саме звідси беруться файли `.tar.gz`. Частина `.tar` означає, що це архів, а `.gz` — що його потім стиснули через gzip.

---

## `tar` — об'єднання файлів разом

`tar` розшифровується як "Tape Archive" — назва походить від епохи, коли резервні копії зберігалися на магнітній стрічці. Назва стара, сам інструмент — ні.

**Створення архіву:**

```bash
tar -cvf archive.tar file1.txt file2.txt file3.txt
```

Розбір прапорців:
- `-c` — створити новий архів
- `-v` — verbose, показувати, що додається (необов'язково, але корисно)
- `-f` — наступний аргумент — ім'я файлу архіву

Результат — `archive.tar`: один файл, що містить усі три.

**Розпакування архіву:**

```bash
tar -xvf archive.tar
```

- `-x` — розпакувати
- `-v` — verbose
- `-f` — файл, з якого розпаковувати

Це розміщує файли в поточній директорії.

**Перегляд вмісту без розпаковування:**

```bash
tar -tvf archive.tar
```

- `-t` — показати вміст

Корисно, якщо хтось дає тобі tar-файл і ти хочеш побачити, що всередині, перш ніж розпаковувати його.

---

## `gzip` та `gunzip` — робимо файли меншими

`gzip` стискає одиночний файл "на місці" — оригінал зникає і замінюється версією з розширенням `.gz`.

```bash
gzip archive.tar
```

Результат: `archive.tar` зникає і з'являється `archive.tar.gz`.

Щоб розпакувати:

```bash
gunzip archive.tar.gz
```

Або еквівалентно:

```bash
gzip -d archive.tar.gz
```

Обидва роблять те саме — відновлюють оригінальний файл.

---

## Робимо обидва кроки одночасно — `tar.gz`

Замість того, щоб запускати `tar`, а потім `gzip`, можна виконати в один виклик із прапором `-z`:

**Створити стиснений архів:**

```bash
tar -cvzf archive.tar.gz file1.txt file2.txt file3.txt
```

`z` у прапорах означає "також стискати через gzip".

**Розпакувати стиснений архів:**

```bash
tar -xvzf archive.tar.gz
```

Те саме: `x` — розпакувати, `z` — обробити шар gzip.

Це формат, який ти побачиш найчастіше. Коли хтось каже "tar-ball", зазвичай мається на увазі `.tar.gz`.

---

## `bzip2` — альтернатива `gzip`

`bzip2` — ще один інструмент стиснення. Зазвичай він дає трохи менші файли, ніж gzip, але займає довше на стискання/розпакування. Для більшості цілей різниця невелика, але варто знати, що обидва існують.

| | gzip | bzip2 |
|---|---|---|
| Швидкість | Швидше | Повільніше |
| Ступінь стиснення | Добрий | Краще |
| Розширення | `.gz` | `.bz2` |
| Прапор tar | `-z` | `-j` |

Через tar:

```bash
tar -cvjf archive.tar.bz2 files/
```

Розпакувати:

```bash
tar -xvjf archive.tar.bz2
```

Єдина різниця — `-j` замість `-z`.

---

## `dd` — копіювання на низькому рівні

`dd` знаходиться в зовсім іншій категорії, ніж інші інструменти тут. У той час, як `tar` і `gzip` працюють з файлами та каталогами, `dd` працює на рівні raw disk — сирого диска. Він копіює дані блок за блоком, байт за байтом, не звертаючи уваги на структуру файлової системи.

```bash
dd if=/dev/sda of=/dev/sdb
```

- `if` — input file (джерело)
- `of` — output file (призначення)

Це копіює кожен біт із `/dev/sda` (першого жорсткого диска) на `/dev/sdb` (другий диск). Копія ідеальна — вона включає видалені файли, метадані файлової системи, усе. Призначення стає точним клоном джерела.

**Створення образу диска у файлі:**

```bash
dd if=/dev/sda of=disk_image.img
```

Це зберігає весь диск як файл замість копіювання на інший диск. Форензичні експерти це роблять, щоб працювати з образом, не торкаючись оригінального доказу.

**Чому його називають "Data Destroyer":**

Якщо переплутати `if` і `of` або вказати неправильний диск, ти перезапишеш реальний диск нулями або сміттям. Немає підтвердження. Немає undo.

```bash
dd if=/dev/sdb of=/dev/sda    ← перезаписує головний диск тим, що є на sdb
```

Завжди перевіряй `if` і `of` перед запуском `dd`. Навіть краще — перевіряй тричі, якщо одне з них є реальним диском.

**Додати індикатор прогресу:**

За замовчуванням `dd` працює без звуку. Ти не знаєш, як далеко він зайшов. Додай `status=progress`, щоб бачити вивід:

```bash
dd if=/dev/sda of=disk_image.img status=progress
```

---

## Кут з форензики

`dd` — стандартний інструмент цифрової форензики. Коли слідчий захоплює комп'ютер, він не працює напряму з оригінальним диском — спочатку робить образ через `dd`, а потім аналізує образ. Так доказ ніколи не торкають і не змінюють.

Оскільки `dd` копіює на рівні блоків, він захоплює все: файли, видалені файли, фрагменти, структуру файлової системи, slack space. Відтак інструменти на кшталт Autopsy і Sleuth Kit можуть аналізувати образ і відновлювати дані, які були б непомітні звичайним переглядом файлів.

## Довідка по командам

| Команда | Що робить |
|---|---|
| `tar -cvf archive.tar files` | Створити tar-архів |
| `tar -xvf archive.tar` | Розпакувати tar-архів |
| `tar -tvf archive.tar` | Показати вміст tar-архіву |
| `tar -cvzf archive.tar.gz files` | Створити gzip-стиснений архів |
| `tar -xvzf archive.tar.gz` | Розпакувати gzip-стиснений архів |
| `tar -cvjf archive.tar.bz2 files` | Створити bzip2-стиснений архів |
| `tar -xvjf archive.tar.bz2` | Розпакувати bzip2-стиснений архів |
| `gzip filename` | Стиснути файл через gzip |
| `gunzip filename.gz` | Розпакувати `.gz` файл |
| `dd if=source of=destination` | Скопіювати raw blocks з джерела в призначення |
| `dd if=/dev/sda of=image.img status=progress` | Створити образ диска із виводом прогресу |

## Коротка довідка по прапорах tar

| Прапор | Значення |
|---|---|
| `-c` | Створити новий архів |
| `-x` | Розпакувати архів |
| `-t` | Показати вміст |
| `-v` | Verbose-вивід |
| `-f` | Вказати ім'я файлу |
| `-z` | Використати gzip-стиснення |
| `-j` | Використати bzip2-стиснення |

## Практика

- Створи три порожні текстові файли за допомогою `touch file1.txt file2.txt file3.txt`
- Зберіть їх в tar-архів: `tar -cvf bundle.tar file1.txt file2.txt file3.txt`
- Стисни його: `gzip bundle.tar` — а потім виконай `ls -lh` і подивися на різницю в розмірі
- Розпакуй його назад за допомогою `tar -xvzf bundle.tar.gz` і переконайся, що файли є на місці
- Зроби те саме з `bzip2` і порівняй кінцеві розміри між `.tar.gz` і `.tar.bz2`
