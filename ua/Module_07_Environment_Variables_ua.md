# Linux Basics for Hackers
## Модуль 7 — Змінні середовища

---

## Про що цей модуль

Твоя Linux-система працює на наборі прихованих налаштувань, які керують усім — де вона шукає програми, хто ти такий, де твій домашній каталог, як виглядає підказка в терміналі. Все це називається **змінними середовища**. Вони завжди є, просто ти ще їх не бачив.

---

## Що таке змінні середовища насправді

Змінна середовища — це просто іменоване значення, яке система зберігає в пам'яті, поки ти увійшов у сеанс. Програми та сам оболонка постійно читають ці значення, щоб вирішити, як поводитися.

Деякі з них задаються системою під час завантаження. Деякі — під час входу в систему. А ти можеш створювати або змінювати власні в будь-який момент.

Спосіб іменування простий: назви змінних зазвичай пишуться великими літерами, а звертаються до них, ставлячи `$` перед ім'ям.

```bash
echo $HOME
```

Вивід:
```
/home/kali
```

---

## Найважливіші змінні, які варто знати

| Змінна | Що містить |
|---|---|
| `$PATH` | Список папок, у яких система шукає програму під час введення команди |
| `$HOME` | Шлях до твого домашнього каталогу |
| `$USER` | Твоє поточне ім'я користувача |
| `$SHELL` | Яка оболонка в тебе запущена (зазвичай /bin/bash) |
| `$HISTSIZE` | Скільки команд зберігається в історії |
| `$PS1` | Як виглядає підказка командного рядка |

---

## `$PATH` — найважливіша з усіх

`$PATH` — це список шляхів до папок, розділених двокрапками. Коли ти вводиш команду на кшталт `ls`, система не знає "звідки вона береться" магічно. Вона проходить по всіх папках, перерахованих у `$PATH`, одну за одною, поки не знайде програму з такою назвою.

```bash
echo $PATH
```

Вивід:
```
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

Кожна папка, відокремлена `:`, — це місце, де система буде шукати.

Саме тому іноді виникає помилка "command not found". Ти встановив інструмент, але його папка не в `$PATH`, тож система просто не знає, куди дивитися. Виправлення — додати цю папку до `PATH`, що описано нижче.

**Якщо зламати змінну `$PATH`**, ти втрачаєш можливість запускати майже будь-яку команду, бо система не зможе їх знайти. Це виправимо, але незручно. Будь обережний, редагуючи її.

---

## Як переглядати всі змінні середовища

```bash
env
```

Ця команда друкує всі змінні середовища, які зараз встановлені в твоєму сеансі. Їх буде більше, ніж ти очікуєш. Прокрути список, і більшість із них тобі буде знайома.

---

## Зміна та створення змінних

Щоб створити або змінити змінну тільки для поточного термінала:

```bash
MYVAR="hello"
echo $MYVAR
```

Вивід:
```
hello
```

Проблема в тому, що вона зникає в той момент, як ти закриваєш термінал. Щоб зробити її доступною для дочірніх процесів (програм, які ти запускаєш з термінала), її треба **експортувати**:

```bash
export MYVAR="hello"
```

Тепер будь-яка програма, запущена з цього термінала, зможе читати `$MYVAR`.

Щоб додати папку до `$PATH`, не перезаписуючи існуюче значення:

```bash
export PATH=$PATH:/new/folder/here
```

`$PATH` на початку зберігає все, що вже було. Ти просто додаєш `:new/folder/here` наприкінці. Якщо забути цю частину і написати просто `/new/folder/here`, ти знищиш решту значення і повністю зламаєш `PATH`.

---

## Робимо зміни постійними

`export` діє тільки в поточному сеансі. Щоб змінна зберігалася між перезавантаженнями і новими терміналами, її треба додати до конфігураційного файлу оболонки.

Для bash таким файлом є `~/.bashrc`. Відкрий його і додай рядок експорту внизу:

```bash
export PATH=$PATH:/your/new/tool/folder
```

Збережи файл. Потім або відкрий новий термінал, або виконай:

```bash
source ~/.bashrc
```

Це перезавантажує файл без перезапуску.

---

## Зміна підказки — `PS1`

`$PS1` контролює, як виглядає твоя командна підказка. За замовчуванням там щось типу `kali@kali:~$`. Ти можеш змінити її на що завгодно.

```bash
export PS1="Hacker-Level-99: # "
```

Тепер твоя підказка виглядає так:
```
Hacker-Level-99: # 
```

Це здебільшого косметика, але деякі люди ставлять туди корисну інформацію — поточну директорію, гілку git, час. На цей момент достатньо знати, що саме `PS1` керує підказкою і її можна редагувати.

---

## Трюк із історією, який використовують хакери

`$HISTSIZE` контролює, скільки команд зберігається у файлі історії. Коли ти натискаєш стрілку вгору і переглядаєш попередні команди, це і є історія.

```bash
export HISTSIZE=0
```

Якщо встановити 0, нічого не буде зберігатися. Термінал перестає записувати команди до кінця цього сеансу. Після закриття термінала будь-хто, хто відкриє файл історії, не побачить те, що ти запускал.

Це базовий захисний прийом безпеки. Якщо ти знаходишся в системі, де не повинен бути, і не хочеш залишати слідів, це один із перших кроків.

## Довідка по командам

| Команда | Що робить |
|---|---|
| `env` | Вивести всі поточні змінні середовища |
| `echo $VAR` | Вивести значення конкретної змінної |
| `MYVAR="value"` | Створити змінну для поточного сеансу |
| `export MYVAR="value"` | Створити змінну, доступну також дочірнім процесам |
| `export PATH=$PATH:/folder` | Додати папку до `$PATH`, не руйнуючи існуючі значення |
| `source ~/.bashrc` | Перечитати конфігураційний файл bash без перезапуску |

---

## Практика

- Виконай `env` і знайди змінну `$SHELL` — вона покаже, під якою оболонкою ти працюєш
- Виконай `echo $PATH` і подивися на всі папки в списку — це всі місця, де система шукає програми
- Спробуй `export HISTSIZE=0`, а потім натисни стрілку вгору — історія зникне для цього сеансу
- Зміни `PS1` так, щоб показувалося твоє ім'я або будь-який кастомний текст і спостерігай, як підказка змінюється миттєво
