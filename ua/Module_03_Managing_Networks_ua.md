# Linux Basics for Hackers
## Модуль 3 — Керування мережею

---

## Про що цей модуль

Хакерство майже завжди відбувається через мережу. Перш ніж ти зможеш зробити щось у мережі, тобі потрібно зрозуміти власну ідентичність у ній — IP-адресу, MAC-адресу — і як керувати обома. Цей модуль пояснює, як читати інформацію про мережу, змінювати її та розуміти основи роботи DNS.

---

## Дві адреси у кожного пристрою

Кожен пристрій у мережі має два ідентифікатори:

**IP-адреса** — це логічна адреса пристрою в мережі. Її призначає маршрутизатор (або ти сам вручну), і саме за нею дані знають, куди йти. Уяви це як вулицю та будинок — вона говорить мережі, де ти знаходишся, але може змінюватися.

**MAC-адреса** — це адреса, вбудована в фізичну мережеву карту виробником. Це ідентифікатор на рівні апаратного забезпечення, 12 шістнадцяткових символів, унікальний для кожного мережевого інтерфейсу у світі. Вона виглядає так: `00:1A:2B:3C:4D:5E`. На відміну від IP-адреси, її не можна назавжди змінити — але можна тимчасово підробити.

Розуміння обох важливе, бо в мережі саме вони ідентифікують тебе. Вміти читати й змінювати їх — базовий навик.

## Команди

### ifconfig

Це головний інструмент для читання та керування мережевими інтерфейсами. Запусти його без аргументів — і він покаже всю поточну конфігурацію мережі.

```bash
ifconfig
```

У виводі відображаються інтерфейси, які має твій пристрій. Найпоширеніші:

| Інтерфейс | Що це |
|---|---|
| `eth0` | Проводове Ethernet-підключення |
| `wlan0` | Бездротове (Wi‑Fi) підключення |
| `lo` | Loopback — система говорить сама з собою, завжди 127.0.0.1 |

У виводі шукай `inet` — це твоя поточна IP-адреса. Шукай `ether` — це твоя MAC-адреса.

Щоб побачити конкретний інтерфейс:

```bash
ifconfig eth0
```

Щоб призначити нову IP-адресу інтерфейсу:

```bash
ifconfig eth0 192.168.1.100
```

Щоб одночасно встановити маску підмережі:

```bash
ifconfig eth0 192.168.1.100 netmask 255.255.255.0
```

Щоб увімкнути або вимкнути інтерфейс:

```bash
ifconfig eth0 up
ifconfig eth0 down
```

Іноді потрібно вимкнути й знову увімкнути інтерфейс після внесення змін.

---

### iwconfig

Подібно до `ifconfig`, але спеціально для бездротових інтерфейсів. Показує інформацію про Wi‑Fi: назву мережі (ESSID), потужність сигналу та швидкість передачі.

```bash
iwconfig
```

Зазвичай ти просто читаєш з цього, а не записуєш. Але це корисно для того, щоб підтвердити, до якої бездротової мережі ти підключений і як виглядає сигнал.

---

### dhclient

Коли ти вручну задав IP-адресу через `ifconfig`, система більше не отримує її автоматично від маршрутизатора. Якщо хочеш повернутися до автоматичного IP від мережі, використовуй `dhclient`.

```bash
dhclient eth0
```

Це надсилає запит серверу DHCP з фразою "дай мені IP-адресу", і він призначає її. Якщо ти вручну змінив IP і втратив інтернет, зазвичай це і виправляє проблему.

Також можна використовувати це для отримання нової IP-адреси, якщо вважаєш, що поточна викликає проблеми:

```bash
dhclient -r eth0     звільняє поточну IP-адресу
dhclient eth0        запитує нову
```

---

### Зміна MAC-адреси

MAC-адреси призначені для постійного використання, але їх легко підробити на рівні програмного забезпечення. Зміна триває лише до перезавантаження — після цього повертається справжня апаратна MAC-адреса.

Спочатку вимкни інтерфейс:

```bash
ifconfig eth0 down
```

Потім встанови нову MAC:

```bash
ifconfig eth0 hw ether 00:11:22:33:44:55
```

Потім увімкни його назад:

```bash
ifconfig eth0 up
```

Запусти `ifconfig eth0`, щоб перевірити, чи зміна пройшла. Рядок `ether` тепер повинен показувати нову MAC-адресу.

> Зміна MAC-адреси існує тільки в пам'яті. Вона не зберігається після перезавантаження. Якщо потрібна постійна зміна, є інструменти на кшталт `macchanger`, які роблять це чистіше.

### dig

`dig` служить для запитів до DNS — системи, яка переводить доменні імена типу `google.com` в IP-адреси. Він дає більше деталей, ніж просто ping до домену.

```bash
dig google.com
```

Розділ `ANSWER SECTION` у виводі показує IP-адреси, на які розв'язується `google.com`.

Щоб знайти записи поштових серверів:

```bash
dig google.com mx
```

`mx` означає Mail Exchange — це вказує, які сервери обробляють пошту для домену. Корисно для reconnaissance.

Інші типи записів, які варто знати:

| Тип запису | Що показує |
|---|---|
| `a` | IPv4-адреса домену |
| `aaaa` | IPv6-адреса |
| `mx` | Поштові сервери |
| `ns` | Сервери імен (які DNS-сервери є авторитетними) |
| `txt` | Текстові записи — часто містять перевірочні дані |

```bash
dig google.com ns
```

---

### DNS — коротка примітка про важливість

DNS (Domain Name System) — це адресна книга інтернету. Коли ти вводиш `google.com`, твій комп'ютер звертається до DNS-сервера: "яка IP-адреса для google.com?" і отримує відповідь. Без DNS тобі довелося б запам'ятовувати IP-адреси кожного сайту.

Хакери цікавляться DNS з кількох причин. По-перше, DNS-запити можуть багато розповісти про інфраструктуру цілі — поштові сервери, піддомени, сервери імен. По-друге, DNS можна маніпулювати — якщо ти зможеш перенаправити відповіді DNS, ти зможеш відправити людей на неправильний сервер повністю (це називається DNS poisoning або DNS spoofing, про що йдеться в наступних модулях).

Поки що достатньо знати, як використовувати `dig` для читання DNS-записів.

## Довідка по командам

| Завдання | Команда |
|---|---|
| Подивитися всі мережеві інтерфейси | `ifconfig` |
| Подивитися один інтерфейс | `ifconfig eth0` |
| Встановити IP-адресу | `ifconfig eth0 192.168.1.100` |
| Вимкнути/увімкнути інтерфейс | `ifconfig eth0 down / up` |
| Подивитися бездротову інформацію | `iwconfig` |
| Отримати IP від DHCP | `dhclient eth0` |
| Випустити поточну IP | `dhclient -r eth0` |
| Підробити MAC-адресу | `ifconfig eth0 hw ether 00:11:22:33:44:55` |
| DNS-запит | `dig google.com` |
| Знайти поштові сервери | `dig google.com mx` |

---

## Практика

- Запусти `ifconfig` і знайди IP-адресу та MAC-адресу для `eth0` або `wlan0`
- Запусти `dig google.com` і прочитай секцію answer — зверни увагу на повернуті IP-адреси
- Запусти `dig google.com mx` і подивись, які сервери обробляють пошту Google
- Спробуй змінити свою IP на `192.168.1.100`, підтверди це через `ifconfig`, а потім запусти `dhclient eth0`, щоб отримати свіжу IP від DHCP
