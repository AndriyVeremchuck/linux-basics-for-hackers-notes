# Linux Basics for Hackers
## Модуль 1 — Основи терміналу

---

## Про що цей модуль

У Windows ти клікаєш. У Linux ти вводиш команди. Саме в цьому і полягає зміна, про яку йдеться в цьому модулі. Термінал — це місце, де ти проводиш більшу частину часу як хакер, і майже кожен інструмент, який ти згодом будеш використовувати, запускається через нього. Тут немає обходу.

---

## Що таке термінал насправді

Термінал — це текстове вікно, де ти даєш комп'ютеру прямі інструкції, а він відповідає. Немає іконок, меню чи миші. Ти просто вводиш текст, а система виконує саме те, що ти сказав.

Більшість хакерських інструментів взагалі не мають графічного інтерфейсу — без кнопок, вікон, нічого, за що можна клацнути. Якщо ти не вмієш користуватися терміналом, ти не зможеш користуватися інструментами. Все так просто.

Цікаво думати про термінал як про розмову з комп'ютером. Замість того, щоб шукати папку і двічі клацати по ній, ти просто вводиш шлях, куди хочеш перейти, і опиняєшся там миттєво. Спочатку це здається повільним, але згодом відчуття швидкості стає вищим, ніж у будь-якому GUI.

## Файлова система Linux — перевернуте дерево

Linux зберігає все в одній структурі, яка розгалужується від однієї стартової точки вгорі. Ця стартова точка називається **root** і записується як `/` — просто коса риска.

Усе в системі — файли, папки, програми, налаштування — живе десь усередині цього дерева.

```
/
├── etc/        системні налаштування та конфігураційні файли
├── bin/        основні вбудовані програми
├── home/       особисті папки кожного користувача
│   └── kali/   твоя домашня папка
├── root/       домашня папка для користувача root (адміністратор)
├── var/        логи та дані, що постійно змінюються
├── tmp/        тимчасові файли, очищуються при кожному перезавантаженні
└── usr/        встановлене програмне забезпечення та додатки
```

Якщо ти приходиш з Windows: Windows використовує `C:\Users\YourName\` як домашню папку. Linux використовує `/home/yourname/`. Та сама ідея, інший синтаксис.

Основні папки, які варто запам'ятати прямо зараз:

| Папка | Що міститься |
|---|---|
| `/` | Root — вершина всього |
| `/etc` | Конфігураційні файли — тут живуть системні параметри |
| `/bin` | Базові програми, без яких система не може працювати |
| `/home` | Особисті папки звичайних користувачів |
| `/root` | Домашня папка для користувача root |
| `/tmp` | Тимчасові файли — очищаються при кожному перезавантаженні |

## Команди

### pwd

Скорочення від "Print Working Directory". Показує, де ти зараз знаходишся у файловій системі.

```bash
pwd
```

Приклад виводу:
```
/home/kali
```

Ти знаходишся в папці `kali`, усередині `home`, на верхньому рівні системи. Використовуй цю команду, коли відчуваєш, що заблукав.

---

### ls

Скорочення від "List". Показує, що знаходиться в поточній папці.

```bash
ls
```

Приклад виводу:
```
Desktop  Documents  Downloads  Pictures
```

Корисні варіанти:

| Команда | Що змінюється |
|---|---|
| `ls` | Базовий список |
| `ls -l` | Детальний список з правами доступу, розміром і датою |
| `ls -a` | Показує також приховані файли |
| `ls -la` | Детальний список із прихованими файлами |

Приховані файли в Linux починаються з крапки — наприклад `.bashrc` або `.config`. Вони не відображаються простим `ls`. Використовуй `ls -la`, коли потрібно побачити все, і ти будеш використовувати це часто.

---

### cd

Скорочення від "Change Directory". Саме так ти переміщуєшся по файловій системі.

```bash
cd /etc
```

Перехід безпосередньо до `/etc`.

Швидкі команди, які варто запам'ятати:

| Команда | Куди веде |
|---|---|
| `cd /path` | Відразу до вказаного шляху |
| `cd ..` | На один рівень вище до батьківської папки |
| `cd ~` | Відразу до домашньої папки |
| `cd /` | Повністю на кореневий рівень |
| `cd -` | Назад до попередньої папки, де ти був |

`cd ..` — це та команда, яку ти будеш використовувати постійно. Якщо ти глибоко в дереві і хочеш піднятися назад, просто повторюй `cd ..`, поки не опинишся там, куди треба.

---

### man

Скорочення від "Manual". У кожної команди в Linux є вбудований мануал, який пояснює, що вона робить, і перераховує всі доступні опції.

```bash
man ls
```

Відкриває повний мануал для `ls`.

Усередині мануалу:
- Прокручуй вниз клавішею `j` або стрілкою вниз
- Прокручуй вгору клавішею `k` або стрілкою вгору
- Шукай слово, натиснувши `/`, а потім ввівши його
- Вийди, натиснувши `q`

Коли ти стикаєшся з новим інструментом, `man toolname` — це перша команда, яку варто виконати. Відповідь зазвичай там є.

---

### whoami

Показує, під яким користувачем ти зараз увійшов у систему.

```bash
whoami
```

Вивід:
```
kali
```

Або якщо ти працюєш як адміністратор:
```
root
```

Це дуже важливо пізніше. Деякі команди вимагають прав root і не працюють від імені звичайного користувача. Знання того, під яким обліковим записом ти працюєш, економить багато плутанини.

---

### locate

Шукає файл у всій файловій системі за назвою.

```bash
locate nmap
```

Знаходить усі файли в системі, де є назва "nmap".

Одна важлива річ: `locate` працює з попередньо збудованою базою даних, а не сканує диск у реальному часі. Якщо ти щойно щось встановив, і `locate` не знаходить це, спочатку онови базу даних:

```bash
updatedb
```

Ця команда вимагає прав root. Виконай її один раз, і тоді `locate` буде актуальним.

## Одне правило, яке не можна забувати

**Linux чутливий до регістру.** Це збиває майже кожного новачка.

```bash
cd Desktop     працює
cd desktop     помилка — такого файлу немає
cd DESKTOP     помилка — такого файлу немає
```

`Desktop`, `desktop` і `DESKTOP` — це три різні речі для Linux. Завжди стеж за регістром літер.

## Як виглядає навігація на практиці

```
/
└── home/
    └── kali/
        ├── Desktop/
        └── Downloads/

Ти знаходишся в /home/kali. Ти хочеш перейти до Desktop:
  cd Desktop             на один рівень вниз
  cd ..                  назад до /home/kali
  cd ../..               назад до /home
  cd /                   миттєво перейти до кореня з будь-якого місця
  cd ~                   миттєво перейти до /home/kali з будь-якого місця
```

## Довідка по командам

| Команда | Що робить | Приклад |
|---|---|---|
| `pwd` | Показує поточне місцезнаходження | `pwd` |
| `ls` | Виводить список файлів у поточній папці | `ls` |
| `ls -la` | Виводить усе, включно з прихованими файлами | `ls -la` |
| `cd /path` | Перейти до папки | `cd /etc` |
| `cd ..` | Піднятися на один рівень вгору | `cd ..` |
| `cd ~` | Перейти в домашню папку | `cd ~` |
| `man cmd` | Відкрити довідку по команді | `man ls` |
| `whoami` | Показує, під яким користувачем ти працюєш | `whoami` |
| `locate file` | Знайти файл будь-де в системі | `locate nmap` |
| `updatedb` | Оновити базу даних для `locate` | `updatedb` |

## Практика

- Відкрий термінал і виконай `pwd` — подивись, звідки ти стартуєш
- Виконай `cd /`, потім `ls` — ти в корені, подивись, що там є
- Виконай `cd ~`, потім `ls -la` — знайди приховані файли, що починаються з крапки
- Виконай `man nmap`, погортай і вийди через `q`

Мета не в тому, щоб зараз усе це запам'ятати. Мета — почати рухатися руками й відчути себе комфортно в терміналі. Команди самі закріпляться, чим більше ти ними користуєшся.

## 🔄 Сучасний погляд (нотатки з практики системного адміністрування)

Команди вище — це основа, яку варто знати назубок незалежно від дистрибутива й епохи, вони нікуди не подінуться. Але за останні роки з'явився пласт "сучасних" замін класичних утиліт — написаних на Rust/Go, набагато швидших і зручніших для щоденної інтерактивної роботи. Знати про них варто, навіть якщо базові команди залишаються обов'язковими (бо саме вони гарантовано є на будь-якому сервері, куди тебе пустять по SSH):

| Класична утиліта | Сучасна заміна | Чим краща |
|---|---|---|
| `ls` / `ls -la` | **`eza`** (форк застарілого `exa`) | Кольоровий вивід, показує git-статус файлів, вбудована деревовидна структура (`eza --tree`) |
| `cat` | **`bat`** | Підсвітка синтаксису, номери рядків, автоматичний виклик пейджера для довгих файлів |
| `find` | **`fd`** | Простіший і швидший синтаксис, за замовчуванням ігнорує `.gitignore` та приховані файли |
| `grep` (тема наступного модуля) | **`ripgrep` (`rg`)** | На порядки швидший на великих деревах коду, розуміє `.gitignore` |
| ручний пошук в історії команд | **`fzf`** | Інтерактивний нечіткий (fuzzy) пошук — `Ctrl+R` з fzf шукає в історії набагато зручніше, ніж стандартний reverse-i-search |

Встановлення на Kali/Debian: `sudo apt install eza bat fd-find ripgrep fzf`
Встановлення на CachyOS/Arch: `sudo pacman -S eza bat fd ripgrep fzf`

**Практичний висновок:** для написання портативних скриптів і для будь-якої машини, де невідомо, що встановлено, — використовуй `ls`, `cat`, `find`, `grep`. Це те, що буде завжди. Але для власного щоденного інтерактивного термінала — постав ці сучасні заміни й налаштуй aliases (`alias ls='eza'`, `alias cat='bat'` в `~/.bashrc`), це реально економить час щодня.
