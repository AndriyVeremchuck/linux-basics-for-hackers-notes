## Модуль 0 — Початок роботи та налаштування лабораторії

## Про що цей модуль

Перш за все, тобі потрібне безпечне місце для практики. Не хочеться ламати реальний комп'ютер під час навчання. Цей модуль про створення такого безпечного середовища — віртуальної машини з Kali Linux — і про те, чому Linux є основною ОС для хакерів.

---

## Чому Linux?

Windows приховує від тебе багато чого. Більшість речей відбувається "за лаштунками", і ти не повинен займатися цим. Linux — навпаки: усе видно, усе налаштовується, і нічого не заховано.

Дві речі роблять Linux особливим для хакерства:

- **Open source** — весь вихідний код відкритий. Ти можеш читати його, змінювати, збирати заново. Нічого не є "чорною скринькою".
- **Прозорість** — ти можеш побачити, що саме робить система в будь-який момент. Немає прихованих процесів, які не можна перевірити.

Уяви Windows як автомобіль, у якого капот приварений. Ти можеш ним керувати, але не торкатися двигуна. Linux — це той самий автомобіль, але капот завжди відкритий, а всі інструменти лежать на столі.

## Що таке Kali Linux?

Linux існує у багатьох варіантах, які називають **дистрибутивами** (або "distros"). Ubuntu, Fedora, Mint — це всі Linux, просто упаковані для різних цілей.

Kali Linux — це дистрибутив, створений спеціально для фахівців з безпеки. Він постачається з сотнями інструментів для хакерства та тестування на проникнення, тому тобі не потрібно шукати їх по одному і встановлювати вручну. Kali побудований на базі **Debian**, одного з найстаріших і найстабільніших дистрибутивів Linux.

Kali — це стандарт галузі. Це те, чим користуються професіонали, тому ми теж будемо використовувати його.

---

## Віртуальна машина

Віртуальна машина (VM) — це комп'ютер, який працює всередині твого комп'ютера. Вона бере частину апаратного забезпечення — деяку кількість ОЗП і процесорного часу — і запускає окрему операційну систему у своєму вікні.

```
Твій реальний комп'ютер (Windows або macOS)
└── VirtualBox
    └── Kali Linux VM  ← ось тут ти практикуєшся
```

Твій реальний комп'ютер називають **host** (хост). VM називають **guest** (гість). Все, що відбувається всередині гостя, залишається всередині гостя. Якщо щось зламається, ти просто скидаєш VM, і все зникає. Твій хост-комп'ютер навіть не помітить цього.

Саме тому професіонали завжди спочатку тестують експлойти в VM. Якщо ти випадково запустиш щось руйнівне, удар отримує VM, а не твоя реальна система.

---

## VirtualBox та ISO-файл

**VirtualBox** — це безкоштовне програмне забезпечення для створення і запуску VM. Воно розроблене Oracle і працює на Windows, macOS та Linux.

**ISO-файл** — це образ диска: повна копія операційної системи, упакована в один файл. Коли ти завантажуєш Kali Linux, ти завантажуєш саме ISO. VirtualBox використовує цей ISO для встановлення Kali в твою VM так само, як ти встановлював би ОС з фізичного диска.

## Перш ніж встановлювати — що перевірити

**Віртуалізація має бути увімкнена в BIOS.** Це найпоширеніша причина, через яку VirtualBox не запускає VM. Твій процесор підтримує віртуалізацію, але вона іноді вимкнена за замовчуванням у параметрах BIOS.

- Для процесорів Intel: **Intel VT-x**
- Для процесорів AMD: **AMD-V**

Щоб перевірити: перезавантаж комп'ютер і натисни `DEL`, `F2` або `F12` (залежно від материнської плати), щоб увійти в BIOS. Знайди параметр віртуалізації і переконайся, що він увімкнений.

**Розподіл оперативної пам'яті.** Не виділяй VM занадто багато RAM, інакше хост-комп'ютер сильно сповільниться. Просте правило: виділяй 1 ГБ оперативної пам'яті для VM на кожні 4 ГБ у твого комп'ютера.

| Вся оперативна пам'ять | Виділити VM |
|---|---|
| 4 ГБ | 1 ГБ |
| 8 ГБ | 2 ГБ |
| 16 ГБ | 4 ГБ |

**Пароль root.** Під час встановлення Kali запропонує встановити пароль для root. Root — це суперкористувач з необмеженим доступом до системи. Встанови те, що зможеш запам'ятати, навіть якщо зараз воно просте. Пізніше його можна змінити.

## Налаштування

1. Завантаж VirtualBox з virtualbox.org і встанови його.
2. Завантаж ISO-образ Kali Linux 64-bit з kali.org/get-kali.
3. Відкрий VirtualBox → натисни New → назви його "Kali" → тип: Linux → версія: Debian 64-bit.
4. Виділи оперативну пам'ять згідно з таблицею вище.
5. Створи віртуальний жорсткий диск мінімум 20 ГБ.
6. Перейди в Settings → Storage → натисни значок порожнього диска → підключи ISO-файл.
7. Запусти VM і пройди інсталятор Kali.
8. Встанови ім'я користувача та пароль root, коли просять.

Ти дізнаєшся, що все працює, коли побачиш екран входу в Kali з логотипом дракона.

## Основні терміни

| Термін | Що це означає |
|---|---|
| Open Source | Вихідний код відкритий — будь-хто може його читати або змінювати |
| Distribution (distro) | Версія Linux, упакована для певної мети |
| Debian | Стабільна база Linux, на якій побудований Kali |
| Virtual Machine (VM) | "Фальшивий" комп'ютер, що працює всередині твого реального |
| VirtualBox | Програма, яка створює і запускає VM |
| ISO file | Завантажувальний образ диска для встановлення ОС |
| Host | Твій справжній фізичний комп'ютер |
| Guest | VM, що працює всередині хоста |
| Root | Усіма владний адміністратор Linux |
