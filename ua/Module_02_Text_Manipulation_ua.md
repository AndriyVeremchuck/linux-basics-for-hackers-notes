# Linux Basics for Hackers
## Модуль 2 — Маніпуляції з текстом

---

## Про що цей модуль

У Linux майже все — текстовий файл. Системні налаштування, логи, конфіги, дані користувача — усе це текст. Як тільки ти навчишся шукати і редагувати текст, ти зможеш переглядати тисячі рядків виводу і витягувати саме те, що потрібно, за секунди. У цьому і полягає вся суть цього модуля.

---

## Чому це важливо для хакерства

Коли інструмент сканування виконується і видає вивід, він не дає тобі чисту підсумкову інформацію. Він виводить усе — тисячі рядків. Ти не читаєш це вручну. Ти використовуєш текстові інструменти, щоб відфільтрувати все до того, що тобі дійсно потрібно. Реальний приклад: після сканування мережі ти використовуєш `grep`, щоб залишити тільки рядки із словом "open" і знайти відкриті порти, ігноруючи все інше.

Крім того, майже кожна системна конфігурація зберігається як звичайний текстовий файл десь у `/etc`. Якщо ти вмієш читати й редагувати ці файли, ти можеш перевизначити майже будь-що в системі.

## Команди

### cat

Скорочення від "concatenate". Найпростіший спосіб прочитати файл — просто вивести його вміст на екран.

```bash
cat /etc/passwd
```

Також корисно для швидкого створення маленьких файлів:

```bash
cat > targets.txt
```

Після виконання цієї команди вводь вміст рядок за рядком. Коли закінчиш, натисни `Ctrl+D`, щоб зберегти файл і вийти. Все, що ти ввів, тепер знаходиться у `targets.txt`.

Щоб додати вміст до вже існуючого файлу без перезапису, використовуй `>>`:

```bash
cat >> targets.txt
```

Різниця між `>` і `>>` дуже важлива. `>` перезаписує. `>>` додає в кінець.

---

### grep

Це та команда, яку ти використовуватимеш найбільше. `grep` переглядає файл і повертає лише рядки, що містять певне слово або шаблон.

```bash
grep "password" logs.txt
```

Повертає всі рядки у `logs.txt`, які містять слово "password".

Корисні параметри:

| Параметр | Що робить |
|---|---|
| `-i` | Пошук без урахування регістру (знаходить "Password", "PASSWORD" тощо) |
| `-r` | Рекурсивний пошук у всіх файлах папки |
| `-n` | Показати номери рядків поруч із результатами |
| `-v` | Інверсія — показувати рядки, які НЕ містять слово |

Приклад:
```bash
grep -i "admin" access.log
```

Знаходить "admin", "Admin", "ADMIN" — усі вони.

### head та tail

Коли файл дуже великий, а тобі потрібна тільки його невелика частина:

```bash
head /etc/snort/snort.conf
```

Показує перші 10 рядків за замовчуванням.

```bash
tail /var/log/syslog
```

Показує останні 10 рядків за замовчуванням.

Щоб контролювати, скільки рядків отримати:

```bash
head -n 20 file.txt     перші 20 рядків
tail -n 20 file.txt     останні 20 рядків
```

У `tail` є дуже корисна фішка — прапорець `-f`, який слідкує за файлом у реальному часі:

```bash
tail -f /var/log/syslog
```

Це тримає термінал відкритим і показує нові рядки, коли вони додаються до файлу. Корисно для перегляду логів у реальному часі під час виконання чогось.

---

### nl

Додає номери рядків до виводу файлу. Зручно, коли треба посилатися на конкретні рядки.

```bash
nl /etc/snort/snort.conf
```

---

### less

Коли файл занадто довгий, щоб читати його через `cat` (це просто прокручує все в одну мить), використай `less`. Він дозволяє переглядати файл по сторінках.

```bash
less /etc/snort/snort.conf
```

Керування:
- `Space` — наступна сторінка
- `b` — попередня сторінка
- `/word` — пошук слова
- `q` — вихід

---

### sed

Скорочення від "stream editor". Він знаходить слово або шаблон у файлі і замінює його чимось іншим.

```bash
sed 's/mysql/MySQL/g' config.txt
```

Розбір:
- `s/` — заміна
- `mysql` — знайти це
- `/MySQL/` — замінити на це
- `g` — виконати глобально (для всіх входжень, не лише першого)

За замовчуванням `sed` лише виводить змінений результат — він не змінює сам файл. Щоб зберегти зміни у файл, додай `-i`:

```bash
sed -i 's/mysql/MySQL/g' config.txt
```

> Перед використанням `-i` зроби резервну копію. `sed -i` змінює файли назавжди, і повернути нічого не можна.

```bash
cp config.txt config.txt.bak
sed -i 's/old/new/g' config.txt
```

## Конвеєр — з'єднання команд разом

Конвеєр `|` бере вивід однієї команди і передає його напряму в іншу. Саме тут починається справжня сила.

```bash
cat access.log | grep "failed"
```

Замість того, щоб читати весь лог, ти бачиш тільки рядки, що містять "failed".

Можна ланцюжком з'єднувати скільки завгодно конвеєрів:

```bash
cat access.log | grep "failed" | tail -n 20
```

Це читає лог, фільтрує за "failed", а потім показує лише останні 20 рядків із відфільтрованих результатів. Три команди в одному рядку.

---

## Довідка по командам

| Команда | Що робить | Приклад |
|---|---|---|
| `cat file` | Виводить весь файл на екран | `cat /etc/passwd` |
| `cat > file` | Створює файл і вводить дані в нього | `cat > notes.txt` |
| `grep "word" file` | Знаходить рядки, що містять слово | `grep "root" passwd` |
| `grep -i` | Пошук без урахування регістру | `grep -i "admin" log` |
| `head -n 20 file` | Перші 20 рядків | `head -n 20 file.txt` |
| `tail -n 20 file` | Останні 20 рядків | `tail -n 20 file.txt` |
| `tail -f file` | Слідкує за файлом у реальному часі | `tail -f syslog` |
| `nl file` | Показує файл із номерами рядків | `nl config.conf` |
| `less file` | Прокручує файл | `less bigfile.txt` |
| `sed 's/a/b/g' file` | Замінює всі "a" на "b" | `sed 's/old/new/g' f` |
| `cmd1 \| cmd2` | Передає вивід cmd1 до cmd2 | `cat log \| grep fail` |

## Практика

- Перейди до `/etc/snort/` і відкрий `snort.conf` через `less` — прокрути його, щоб зрозуміти, як виглядає конфігураційний файл
- Використай `grep "output" /etc/snort/snort.conf` і подивись, які рядки повертаються
- Використай `cat > targets.txt`, введи три IP-адреси (по одній на рядок), потім натисни `Ctrl+D` — після цього прочитай файл назад через `cat targets.txt`
- Спробуй ланцюжок: `cat /etc/snort/snort.conf | grep "output" | nl`
